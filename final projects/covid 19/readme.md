# 📌 Overview

This project performs **Exploratory Data Analysis (EDA)** on the early global COVID-19 outbreak using Python and Jupyter Notebook.

The notebook demonstrates the complete data analysis pipeline including:

- Data loading
- Data cleaning
- Missing value handling
- Statistical analysis
- Exploratory analysis
- Data visualization
- Insight generation

The project helps understand how COVID-19 spread during the initial outbreak period by analyzing confirmed, deaths, recovered and suspected cases.

---

# 🎯 Project Objective

The primary objectives are:

- Import and explore COVID-19 data
- Clean inconsistent records
- Perform statistical analysis
- Identify affected countries
- Compare confirmed, deaths and recovered cases
- Create meaningful visualizations
- Generate insights from real-world data

# 🚀 Getting Started

## Prerequisites

- Python 3.10+
- Jupyter Notebook

Install required libraries

```bash
pip install pandas
pip install numpy
pip install matplotlib
pip install notebook
```

Launch Notebook

```bash
jupyter notebook
```

Open

```
COVID19_Data_Analysis.ipynb
```

Run all cells.
