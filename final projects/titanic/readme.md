# 📌 Overview

The **Titanic Survival Data Analysis** project performs a comprehensive **Exploratory Data Analysis (EDA)** on the famous Titanic passenger dataset using **Python** and **Jupyter Notebook**.

The notebook demonstrates the complete data analysis workflow including:

- Data loading
- Data preprocessing
- Missing value handling
- Data cleaning
- Statistical analysis
- Exploratory analysis
- Data visualization
- Insight generation

The project explores the factors that influenced passenger survival, such as age, gender, passenger class, fare, and embarkation point.

---

# 🎯 Project Objective

The objectives of this project are:

- Import and explore Titanic passenger data
- Clean and preprocess the dataset
- Handle missing values
- Analyze passenger demographics
- Compare survival rates
- Create meaningful visualizations
- Discover hidden relationships within the dataset

- Python 3.10+
- Jupyter Notebook

```bash

pip install numpy
pip install matplotlib
pip install notebook
```

Launch Jupyter Notebook

```bash

```

Open

```

```

Run all notebook cells.
