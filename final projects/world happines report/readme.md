# 📌 Overview

The **World Happiness Report 2019 Analysis** project performs a comprehensive **Exploratory Data Analysis (EDA)** on the **World Happiness Report 2019** dataset using **Python** and **Jupyter Notebook**.

The notebook demonstrates a complete data analytics workflow including data loading, preprocessing, statistical analysis, visualization, and insight generation to understand the factors influencing happiness across different countries.

This project is ideal for students and beginners learning **Data Analytics**, **Data Visualization**, and **Exploratory Data Analysis (EDA)**.

---

# 🎯 Project Objective

The objectives of this project are:

- Import and inspect the World Happiness dataset
- Clean and preprocess the data
- Handle missing values
- Analyze country-wise happiness scores
- Compare economic and social indicators
- Create meaningful visualizations
- Discover relationships among happiness factors

# 🚀 Installation & Usage

- Python 3.10+
- Jupyter Notebook

```bash

pip install numpy
pip install matplotlib
pip install notebook
```

Launch Jupyter Notebook

```bash

```

Open

```

```

Run all notebook cells.
